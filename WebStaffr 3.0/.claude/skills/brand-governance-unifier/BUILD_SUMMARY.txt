================================================================================
SKILL CAPABILITIES
================================================================================

This skill can:

1. Consolidate 2-10 governance documents into a unified system
2. Resolve contradictions between docs on positioning, voice, rules
3. Eliminate redundancies and establish single source of truth
4. Separate Executive (internal) and Commercial (customer) voice clearly
5. Document and enforce brand/design rules (fonts, colors, punctuation)
6. Audit new copy against existing governance standards
7. Rewrite copy to match brand standards
8. Generate reconciliation memos explaining consolidation decisions
9. Verify output against comprehensive quality checklist
10. Create long-term governance manual from scattered materials

================================================================================
USAGE SCENARIOS
================================================================================

Scenario 1: Consolidating Multiple Documents
  Input: 3-5 conflicting governance docs
  Process: Phase 1 analyze + Phase 2 rewrite
  Output: Consolidated system + reconciliation memo
  Time: 1-2 hours

Scenario 2: Auditing Copy Against Standards
  Input: New marketing/sales copy + existing governance
  Process: Phase 1 analyze standards + Phase 2 audit/rewrite
  Output: Audit report + rewritten copy
  Time: 30 min - 1 hour

Scenario 3: Creating Governance from Principles
  Input: Core principles + brand identity
  Process: Phase 1 establish architecture + Phase 2 create docs
  Output: Complete governance manual
  Time: 2-4 hours

Scenario 4: Bringing Copy Into Compliance
  Input: Existing document + governance standards
  Process: Phase 1 identify violations + Phase 2 rewrite
  Output: Compliant version
  Time: 15-30 min
