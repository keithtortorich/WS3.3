## What Is This?

A **reusable skill** that transforms fragmented, contradictory governance documents into a premium, coherent system that feels like it came from one elite consultancy.

### What It Does
1. **Analyzes** your documents for philosophy, contradictions, gaps (Phase 1)
2. **Rewrites** them using unified principles and consistent voice (Phase 2)
3. **Verifies** against a quality checklist
4. **Delivers** a complete governance manual

### Time Commitment
- **Phase 1 (Analysis)**: 15–30 minutes
- **Phase 2 (Rewriting)**: 30–60 minutes
- **Total**: 1–2 hours for a typical 3–5 document consolidation

## The Two-Phase Process (30-Second Summary)

### Phase 1: Analyze (Understand)
- Read all documents
- Find contradictions, gaps, philosophy
- Establish principles
- Plan new architecture

**Output**: Analysis plan (no rewriting yet)

### Phase 2: Rewrite (Build)
- Rewrite each doc using principles
- Maintain two voices (Executive for internal, Commercial for customers)
- Remove contradictions, outdated material, redundancy
- Verify against quality checklist

**Output**: Unified governance system

## When to Use This Skill

✅ **Use when you have:**
- Multiple governance documents that contradict each other
- Brand docs scattered across different sources
- Different people wrote the docs (feels disjointed)
- Unclear brand rules or visual identity
- Need Executive and Commercial voice separated
- Want one unified manual to guide decisions

❌ **Don't use for:**
- Single document editing (use regular editing)
- One-off copy tasks (use copy-editing tools)
- Visual design work (this is text/strategy)
- Creating governance from scratch without principles
