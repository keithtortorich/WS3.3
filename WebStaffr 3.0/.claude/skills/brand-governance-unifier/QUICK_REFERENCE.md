# Brand Governance Unifier — Quick Reference Card

**TL;DR**: Use this skill when you have multiple brand/governance documents that contradict each other, feel disjointed, or need to be brought into line with standards.

---

## The Two-Phase Process

### Phase 1: Analyze (30 min)
- Read all docs
- Find contradictions, redundancies, gaps
- Establish governing principles
- Plan new document architecture

### Phase 2: Rewrite (60 min)
- Rewrite each doc using principles
- Maintain Executive & Commercial voice
- Remove contradictions & outdated material
- Verify against quality checklist

---

## What to Provide

- All governance documents (as text, paste, or file upload)
- Any specific brand rules (fonts, colors, punctuation bans)
- Intended audience/customer profile
- Philosophy or core principle (if you have one)
- Communication style examples (optional)

---

## What You Get

- Consolidated governance system (reorganized documents)
- Reconciliation memo (explains consolidation decisions)
- Brand rule summary (documented and enforced)
- Quality verification (against 7-point checklist)

---

## Quality Checklist

Final output must have:
- ✓ All documents read as one system
- ✓ No contradictions
- ✓ Every document has distinct purpose
- ✓ Philosophy consistent throughout
- ✓ Writing is premium and authoritative
- ✓ Could serve as long-term manual

---

## Two Communication Styles

### Executive (Internal/Leadership)
Elevated vocabulary, precise, calm authority, accuracy first

### Commercial (Customers/Marketing)
Grade 8 level, simple, outcome-focused, high readability

## Common Contradictions Found

**"We're cutting-edge AI"** vs. **"We fix your furnace"**
→ Solution: Focus on outcome (comfort, peace of mind), not technology

**Enterprise language** vs. **Customer-facing copy**
→ Solution: Separate Executive and Commercial voice clearly

**Marketing says X** vs. **Strategy says Y**
→ Solution: Resolve to one unified positioning

**Scattered brand rules** vs. **No visual governance**
→ Solution: Document all design rules explicitly

## When to Use This Skill

✓ Multiple contradictory governance docs
✓ Brand docs feel disjointed or inconsistent
✓ New copy needs to be audited against standards
✓ Company documents scattered across different sources
✓ Want governance to "feel like one consultancy"
✓ Need Executive & Commercial voice separated
✓ Want to eliminate outdated references

---

## When NOT to Use

✗ Creating governance from scratch (use if you have principles to start)
✗ One-off copy editing (use for single document audit only)
✗ Visual design work (this is text/strategy focused)
✗ Marketing campaign copy (use for campaign strategy docs instead)

## Success Indicators

After consolidation, you'll know it worked if:

1. **Coherence**: Reading all docs together feels like one voice
2. **Clarity**: Purpose of each doc is obvious
3. **Philosophy**: Core principles reinforce throughout
4. **No Contradictions**: Docs support, don't conflict
5. **Premium Tone**: Writing feels intentional and authoritative
6. **Usable**: Team actually references and uses the manual
