- `emergent-voice-and-brand-prompts.md` -- two system prompts from the same project: a per-tenant voice receptionist prompt (comparable to Angel) and an agency chatbot brand-voice prompt (no WS3.3 equivalent exists).
- `angel-vs-emergent-comparison.md` -- analysis comparing the above against Angel's actual current prompt (`webstaffr/workers/angel/angel_prompt.md`) and WS3.3's current design approach (none exists in-repo; frontend is delegated to Lovable). Includes concrete, low-risk recommendations and flags what needs a founder decision before any adoption.
