# Phase 2 Execution Checklist

Use this checklist while actually rewriting documents after Phase 1 analysis is complete.

---

## Pre-Rewrite: Setup

- [ ] Phase 1 analysis complete and documented
- [ ] Governing principles clearly stated
- [ ] New document architecture defined
- [ ] Brand/design rules listed (fonts, colors, punctuation bans)
- [ ] Executive vs. Commercial style examples ready
- [ ] Reconciliation decisions documented (which docs merge, which stay separate)
- [ ] All contradictions identified and resolution plan in place

---

## Document-by-Document Rewrite

### Document 1: ___________________

#### Structure & Organization
- [ ] Document role clearly stated in introduction (1-2 sentences)
- [ ] Scope is distinct from other documents
- [ ] Table of contents or clear section headings
- [ ] Cross-references to related documents (use "See also: Document X" links)

#### Wording & Voice
- [ ] Appropriate communication style (Executive or Commercial)?
- [ ] If Executive: elevated vocabulary, precise language, calm authority
- [ ] If Commercial: Grade 8 reading level, simple language, outcome-focused
- [ ] All examples actually match intended tone
- [ ] No jargon without explanation
- [ ] No brand/company-centric language ("we," "our," "our product")—focus on customer outcomes

#### Removal & Editing
- [ ] All outdated references removed
- [ ] No mentions of "previous," "historically," "old approach"
- [ ] No legacy vendor names or decisions referenced
- [ ] Redundant concepts removed (consolidated into other docs or completely removed)
- [ ] No contradictions with other documents
- [ ] All em dashes replaced with commas or hyphens
- [ ] All forbidden punctuation removed

#### Philosophy Enforcement
- [ ] Complexity principle evident (absorb inside, clarity outside)
- [ ] Outcome-focused positioning (not feature-focused)
- [ ] Core philosophy reinforced through structure and content
- [ ] Governing principles applied consistently
- [ ] Brand rules enforced (colors, fonts, punctuation)

#### Quality Checks
- [ ] Reading level appropriate (use Flesch-Kincaid if measuring)
- [ ] Sentences are clear and concise
- [ ] Examples provided where helpful
- [ ] Key concepts defined before use
- [ ] Formatting is consistent with style guide

## Cross-Document Validation

After rewriting all documents:

### Coherence Check
- [ ] Read all documents as a system (not individually)
- [ ] Does the whole thing feel like one voice?
- [ ] Are contradictions eliminated?
- [ ] Do the documents reinforce each other?

### Philosophy Check
- [ ] Governing principles evident in every document?
- [ ] Complexity principle (absorb inside, clarity outside) consistent?
- [ ] Outcome-focused positioning consistent?
- [ ] Core identity statement reinforced throughout?

### Style Check
- [ ] Executive and Commercial styles clearly separated?
- [ ] Examples provided for each style?
- [ ] No mixing of styles inappropriately?
- [ ] Vocabulary level consistent within each style?

### Brand Rule Compliance
- [ ] No em dashes anywhere?
- [ ] Color codes documented (hex/RGB)?
- [ ] Font families and sizing documented?
- [ ] Logo treatment rules included?
- [ ] All other brand/design rules enforced?

### Redundancy Check
- [ ] Concepts not repeated across documents?
- [ ] Cross-references used instead of duplication?
- [ ] Each document occupies unique territory?

### Legacy Reference Removal
- [ ] No references to "previously," "old," "historical"?
- [ ] No vendor names from past decisions?
- [ ] No apologetic language?
- [ ] Document starts fresh, not as an update to something older?

---

## Final Quality Checklist (Before Delivery)

- [ ] All documents read as one cohesive system ✓
- [ ] No documents contradict each other ✓
- [ ] Every document has a clear, distinct purpose ✓
- [ ] All outdated materials eliminated ✓
- [ ] Philosophy is consistent throughout ✓
- [ ] Writing feels intentional, premium, authoritative ✓
- [ ] Finished work could serve as long-term governance manual ✓

---

## Reconciliation Memo (To Include with Final Delivery)

Prepare a memo explaining:

1. **What was consolidated**: Which original docs were merged, and why
2. **What was separated**: Which concepts stayed in separate docs, and why
3. **Contradictions found and resolved**: List each contradiction and how it was addressed
4. **Redundancies removed**: What was duplicated and is now single-sourced
5. **New document architecture**: Explain the role of each new/reorganized document
6. **Brand rules enforced**: List specific brand rules applied (fonts, colors, punctuation, etc.)
7. **Philosophy integration**: Explain how governing principles are now reflected throughout
8. **Communication styles**: Explain the Executive vs. Commercial separation with examples
